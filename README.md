# AI-Based Object Removal and Image Restoration

## Overview

This project implements an AI-powered image inpainting system capable of automatically removing unwanted objects and reconstructing realistic backgrounds using Stable Diffusion Inpainting.

The system supports:

* Manual Mask Inpainting
* Automatic AI Mask Generation
* Image Restoration
* Background Reconstruction

---

## Technologies Used

* Python
* Stable Diffusion Inpainting
* REMBG
* U²-Net
* OpenCV
* Gradio
